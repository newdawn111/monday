  SALES PIPELINE BOARD
════════════════════════════════════════════════════════════════
  URL: https://monday.com/boards/5084268957

  ☐ 1. Lost Reason → Edit labels
       Add: Price, Timeline, Competitor, Changed Mind, Other

  ☐ 2. Quoted Price (ILS) → ⚙ Customize
       Unit: ₪  Position: Left

  ☐ 3. Expected Profit (ILS) → ⚙ Customize
       Unit: ₪  Position: Left

  ☐ 4. Expected Margin % → ⚙ Customize
       Unit: %  Position: Right

  ☐ 5. Probability % → ⚙ Customize
       Unit: %  Position: Right

  ☐ 6. Add Column → Formula
       Name: Weighted Value
       Formula: {Quoted Price (ILS)} * {Probability %} / 100

  ☐ 7. Add Column → Formula
       Name: Lead Time (days)
       Formula: DAYS({Quote Date}, TODAY())

  PROJECTS & INSTALLATION BOARD
════════════════════════════════════════════════════════════════
  URL: https://monday.com/boards/5084270237

  ☐ 8. Customer Type → Edit labels
       Add: Business, Private

  ☐ 9. Project Status → Edit labels (with colors)
       On Schedule (Green)
       Delayed (Red)
       Waiting on Permits (Orange)
       Completed (Blue)
       Issue (Pink)

  ☐ 10. Equipment Delivered → Edit labels (with colors)
        Not Ordered (Gray)
        Ordered (Orange)
        In Transit (Purple)
        Delivered (Green)

  ☐ 11. Inspection Status → Edit labels (with colors)
        Not Started (Gray)
        Private Inspector Done (Orange)
        Waiting Elec. Co. (Purple)
        All Complete (Green)

  ☐ 12. Contract Value (ILS) → ⚙ Customize
        Unit: ₪  Position: Left

  ☐ 13. Project Cost (ILS) → ⚙ Customize
        Unit: ₪  Position: Left

  ☐ 14. Add Column → Formula
        Name: Project Profit (ILS)
        Formula: {Contract Value (ILS)} - {Project Cost (ILS)}
        Then add currency: ₪

  ☐ 15. Add Column → Formula
        Name: Profit Margin %
        Formula: ({Contract Value (ILS)} - {Project Cost (ILS)}) / {Contract Value (ILS)} * 100
        Then add unit: %

  ☐ 16. Add Column → Formula
        Name: Project Duration (days)
        Formula: DAYS({Installation Start Date}, {Installation End Date})
